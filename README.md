# Xept 安装包

Xept 是一个用 AI 写论文的桌面应用：LaTeX 和 Word 都能写，AI 直接改你的论文、编译、核查参考文献、模拟审稿。用你自己的 AI 账号，不需要注册 Xept。

这个仓库只放安装包，在右边的 **Releases** 里下载最新版本。

## 安装（Mac，Apple 芯片 M1–M4）

1. 下载 `Xept-版本号-arm64.dmg`，双击打开，把 **Xept** 拖进「应用程序」。
2. 测试版还没有 Apple 签名，第一次打开会被系统拦住，二选一：
   - 在「应用程序」里**右键 Xept → 打开**，再点「打开」；
   - 或者在「系统设置 → 隐私与安全性」最下面点「仍要打开」。
3. 打开后在「账号设置」里填上你的 AI 账号（Claude、ChatGPT、DeepSeek、Kimi、智谱 GLM 都可以）。

第一次打开时，系统可能会问 Xept 能不能访问钥匙串（用来加密保存你的 AI 账号）、桌面或文稿文件夹（打开放在那里的论文时），都点「允许」。
